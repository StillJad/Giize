# Open-source foundations

- Open Ticket v4.2.2: https://github.com/open-discord-bots/open-ticket, pinned commit 6ffe2d1ea7d89e5bd3e885ba6e7bb63c50477083, GPL-3.0-only. Full source and license retained in vendor/open-ticket. Glurps adds a same-client plugin, administrator-only command policy, support/report/appeal presets, and local HTML transcript generation.
- Open Discord framework: https://github.com/open-discord-bots/framework, used by Open Ticket.
- discord-html-transcripts: https://github.com/ItzDerock/discord-html-transcripts, Apache-2.0. Generates local HTML archives instead of using the upstream external transcript service.
- discord.js: https://github.com/discordjs/discord.js, Apache-2.0.
- jsonc-parser: https://github.com/microsoft/node-jsonc-parser, MIT.

Glurps event applications, moderation additions, leveling rules, and integration glue are custom. Dependency packages retain their own license files. This distribution includes the GPL license and the complete modified Open Ticket source.
